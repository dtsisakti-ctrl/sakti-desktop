# 10-core-server-protocol: Module Overview

The Core Server & Protocol module implements the authoritative attempt state machine, precision timing formulas, background scheduler, Ed25519 cryptographic key management, and client wire protocol.

### Models Owned
- `Attempt`
- `StateTransition`
- `DeviceSession`
- `Command`
- `Event`
- `Incident`
- `SigningKey`
- `TrustAnchor`
