# 30-admin-web-console: Module Overview

Coordinates the Admin Web back-office interface served at `/admin/`, live monitoring grid with real-time candidate tiles, incident aggregation timelines, and staff emergency actions.

### Views & Components Owned (in `examguard-web/src/admin`)
- `LiveMonitoringView.tsx`
- `CandidateDetailDrawer.tsx`
- `IncidentReviewDialog.tsx`
- `EmergencyActionsModal.tsx`
- `ExamsListView.tsx`
