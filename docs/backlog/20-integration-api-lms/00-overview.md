# 20-integration-api-lms: Module Overview

Coordinates external LMS integrations, Attestation Token verification, cryptographically signed outgoing webhooks, encrypted identity photo verification (selfie + ID card), and emergency challenge–response unlock codes.

### Models Owned
- `IntegrationCredential`
- `WebhookSubscription`
- `WebhookDelivery`
- `IdentityPhoto`
- `EmergencyBackupCode`
